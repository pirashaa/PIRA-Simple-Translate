# Changelog

## 1.0.1
- Corrected provider settings lookup in the service worker.
- Added request timeouts and structured API errors.
- Added empty/oversized input validation and explicit provider-key errors.
- Moved API credentials to local extension storage and migrated legacy synced credentials.
- Added settings behavior for excluded domains, modifier key and popup controls.
- Removed broad required all-sites host permission; optional host access is requested for a configured LibreTranslate server.
- Added privacy and Chrome Web Store documentation.
