PIRA Simple Translate Privacy Policy

Developer: Pira Code

Last updated: 5 November 2026

Information processed

When a user requests translation, selected or entered text and language choices are sent to the selected translation provider. That provider processes the text to return a translation and may retain it under its own terms and privacy policy.

Providers

  • Google Web Translation uses an unofficial Google web endpoint, not Google Cloud Translation.
  • Google Cloud Translation uses the user's API key.
  • DeepL uses the user's API key.
  • LibreTranslate sends text to the server URL configured by the user.

Users should review the selected provider's terms and avoid submitting confidential or sensitive text unless they accept that provider's processing.

Storage

Preferences use Chrome sync storage. Provider API keys are stored in local extension storage. This is not a secure secrets vault; use provider-side key restrictions and spending limits.

Tracking and sale

The extension does not intentionally add analytics or advertising trackers. Pira Code does not operate the translation server and does not sell submitted text. The selected provider receives text necessary to perform the requested translation.

Retention and deletion

The extension does not maintain a translation history database. Remove the extension or clear its stored data to delete local extension data. Provider retention is governed by the provider.

Contact

Developer: Pira Code. Contact details should be provided through the developer contact information on the Chrome Web Store listing.
